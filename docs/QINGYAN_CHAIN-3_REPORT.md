## 1. 做了什么

| 场景 | 以前 | 现在（开关打开） |
|---|---|---|
| 情报页签「供应链情报」槽 | 一句「规划中：M3 海关数据源……」 | 进口线索摘要（几家出口商、几条线索、前 3 家；存着但在等确认 / 中标者读不出时照实说）+「导入 / 查看进口线索」；点开在槽位网格下方整行显示面板 |
| 用户在别处查到「中标者从谁那里进口」 | 只能记在别处 | 把表格连同表头贴进来（逗号或制表符分隔，含引号与单元格换行）；表头整格认列（中英别名），日期写法由人每批选（年在前默认 / 月日年 / 日月年），有问题的记录按原因归并报出，重复的跳过；系统不访问任何网站、不调模型 |
| 与中标者比对 | — | 本采购方的历史中标者（授标记录，剔除我方结果）按 TI-3a 三档：同名 / 已确认的挂上；疑似同一家（只差公司后缀、整词包含）等人确认或否决（先弹确认框，写明对全组织生效、不能撤回）；无关的不导入、列出进口商名称 |
| 出口商汇总 | — | 每家：供货给哪家中标者、共几票 / 近 12 个月几票、最近一票（超过 12 个月标出）、和本标要求重合的英文词、供应商库状态；按近 12 个月票数排序；不打「推荐」 |
| 加入供应商库 | — | 一键：已关联过的用那一家；本组织规整后同名的关联一家（在用有邮箱的优先，停用的照实说）；都没有才新建（来源 `trade_data`「进口线索」，邮箱留空）；线索经既有关联流程关联；之后新导入的可「关联新导入的 N 条」 |
| 补邮箱 | 供应商详情页只能改评分（询价入口的「补邮箱」也链到这里，走不通） | 详情页能直接补上 / 修改邮箱、启用已停用的 |
| 供应链页信号列表 | — | 这类线索显示平台「进口记录（人工导入）」、来源「人工录入」，不带找厂优先级 |

开关关闭时：三个接口 404，槽位与本功能之前完全相同（读取中也不闪）。

**与任务书的出入（design D1、D4、D4b、D6）**：

1. 新文件不放 `src/lib/tender-competition/`：那个目录的守卫测试要求恰好 5 个文件、禁止碰库（TI-3a「线索层不碰库」）。放新目录 `src/lib/tender-import-leads/`，只调用 TI-3a 的纯函数。
2. 与中标者都无关的记录不导入（不把用户整张表都存进来）。
3. **验收项「加入供应商库并补邮箱后，下一次起草询价的卡上它出现在收件人里，来源写『进口线索』」只做到一半**：加入后它出现在询价入口的供应商列表里（补上邮箱后可选），供应商页显示来源「进口线索」，人勾选后进卡；**自动起草不自动加它**——判断点 4 B 给自动起草加推荐的条件是「首选 / 备选、强制闸通过」，进口线索只是线索，没评估过就进收件人等于把未证实的线索直接变成询价对象。评估成首选 / 备选后经 CHAIN-2 进自动起草。询价入口本身不显示供应商来源。
4. 别名裁决记在审计里（每一对一条、按对查回、加锁、已裁决 409），不存 `settingsJson`。

## 6. 已知限制

- 数据靠用户自己去别处查：美国提单只在中标者（或其美国关联公司）海运进口美国且没申请保密时才有；加拿大不公开逐票报关记录。
- 名称比对只认同名与两条确定性依据：中标者在提单上用了完全不同的法人名时对不上，只能看「没有保存（名称）」再处理。
- 历史中标者取本采购方最新的 200 条授标。
- 每个项目最多 5000 条进口记录。
- 别名裁决对全组织生效、不能撤回（权限是否提高待 GATE）。
- 关联了线索的供应商按既有删除守卫不能删。
- 投标准备度的「进口线索」阶段还不读这里导入的记录（后续）。
- 生产：对 Sunny 打开 `TENDER_IMPORT_LEADS_ENABLED`（需要 Vercel 权限；`T4_AWARD_INTELLIGENCE_SCHEMA_READY` 已开才有中标者可比）。
