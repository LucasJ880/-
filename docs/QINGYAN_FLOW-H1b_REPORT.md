## 1. 问题

FLOW-H1 上线后，工作台最上面的卡片会说「报价齐了，还没定供应商」，而它正下方的决策摘要标题还写着「当前处于"项目分发"阶段」，进度条停在 0%。原因是页面上的阶段读的是阶段记录（项目上的几个时间），而「供应商报价」「项目提交」两段的记录只能人工点「推进」，常常落后于实际。另外，工作台的三步卡（上传 → 分析 → 确认要求）在要求确认之后一直停在第三步，与卡片重复且更粗。

## 2. 做了什么

1. **实际进度**：「下一步」接口多返回三项——实际进度、记录的阶段、显示的阶段。实际进度是按事实这个标到了六段里的哪一段，规则是一个纯函数，从靠后的事实往前看：

   | 事实 | 实际进度 |
   |---|---|
   | 项目有提交时间 | 项目提交 |
   | 最近 20 轮没取消的询价里有供应商已录入报价，或有一份没作废的投标报价单 | 供应商报价 |
   | 这些轮次里有供应商已发出（含之后回复、谢绝、未响应的） | 供应商询价 |
   | 有等待审核或已批准的分析 | 项目解读 |
   | 以上都没有 | 立项 |

   这些事实是「下一步」取数时已经读出来的，没有多查一次库。
2. **显示的阶段 = 记录的阶段与实际进度里靠后的那个**，由接口算好给页面（记录的阶段是接口那一刻从库里读的）。每个页签上方的决策摘要标题、右侧项目上下文、项目进度区的「当前阶段」、六段进度条、完成百分比都用它。记录靠后时（有人手工推进过）以记录为准，实际进度永远不会把显示往回拉。已结束的项目（已中标、未中标、已放弃、已归档）显示的就是记录的阶段。
3. **不一致时写明**：项目进度区多一行说明——「这里显示的是按实际进度得出的阶段。记录的阶段还是「项目分发」——阶段记录没有自动推进，别处（项目列表等）看到的仍是记录的阶段。」两者相同时没有这一行。
4. **三步卡让位**：有「下一步」卡片时不再渲染三步卡；没有卡片时（开关关闭、接口不可用、非招投标项目）照旧。三步卡的代码没有删。

## 3. 需要你知道的取舍

### 3.1 只改显示，没有让阶段记录自动前进——这是留给你的决定

根治的办法是：第一家报价录入时自动把阶段记录写成「供应商报价」（像现在「分析完成 → 项目解读」「第一封询价发出 → 供应商询价」那样）。这次没有做，因为阶段记录还被项目列表、Muse 的 `status`、主动提醒、放弃项目的接口读取，推进时还会同步改 `tenderStatus`；自动写会改变这些地方的行为，而「前进要人工确认」是当初定下的规则。

所以现在是：项目页说实际到了哪一段并写明记录没跟上，别处仍是记录的阶段。**要不要自动推进，需要你定。**

### 3.2 同一页上仍有按记录的阶段说话的地方

- 「提交」页签里的「放弃项目」：按钮是否出现、对话框里的「当前阶段」、接口的把关和存下来的「放弃阶段」，都按记录的阶段。标题写「供应商报价」时，放弃对话框可能写「供应商询价」；极端情况下（没做分析、直接手工发了询价）标题写「供应商询价」而放弃按钮不出现。
- 对话抽屉里「确认推进到某阶段」的卡片：从记录的阶段往前推，可能提议推进到页面已经显示的那一段。
- 情报页签的「流程状态」、工作台的「投标结果」：读的是招投标状态。

这些读写的就是阶段记录本身，这次没有动。3.1 定了之后它们自然一致。

### 3.3 打开页面的头一下仍是旧样子

「下一步」要等项目数据到了才去取。取回之前页面先显示记录的阶段和三步卡，随后换成卡片和实际的阶段（一次跳变）。没有为此把三步卡压住不显示——那样开关关闭时三步卡也会晚出现。

### 3.4 实际进度看的是「有没有」，不是「够不够」

一家报价就算到了「供应商报价」，与阶段记录原来的含义（进入这一段）一致。有投标报价单也算：这时卡片说的是「准备提交」。

### 3.5 项目进度区里的时间轴不跟着变

时间轴画的是阶段记录上的时间。进度条打了勾的阶段，在时间轴上可能没有对应的点。

### 3.6 独立审查发现的问题与处理

开 PR 前请了一个不带结论的独立审查（只给代码和规格，不告诉它我认为对不对）。它查出的问题：

| 发现 | 处理 |
|---|---|
| 新测试里截标日期写死成 2026-12-20，到那天之后进度条的状态会变，CI 会红 | 已修：日期相对当前时间算；渲染测试把时钟定在测试开始那一刻 |
| 那行说明可能说错：批准询价、分析完成会自动把阶段记录往前写，而页面手上的项目数据不会跟着刷新，于是说明写「记录的阶段还是某某、没有自动推进」——其实已经推进了 | 已修：记录的阶段改由接口在同一时刻从库里读出、随响应返回；页面不再拿自己手上的项目数据去比 |
| 已结束的项目进度被抬高：未中标的项目从 40% 变成 90% | 已修：已结束的项目显示记录的阶段 |
| 有投标报价单但没有供应商报价时，卡片说「准备提交」，标题还写「项目解读」 | 已修：投标报价单也算到了「供应商报价」 |
| 页面与组件的测试只核对源码文字，15 个把行为改坏的改动没被发现 | 已修：新增一份把项目进度区真的渲染出来核对的测试；DB 用例补齐 |
| 规格没写全：右侧上下文与各页签的摘要、最近 20 轮的上限、已结束的项目 | 已修：规格、设计、提案同步 |
| 放弃项目的流程、对话抽屉的推进卡片仍按记录的阶段 | 没改，见 3.2 |
| 打开页面的头一下先闪旧状态 | 没改，见 3.3 |
