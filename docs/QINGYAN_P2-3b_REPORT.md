## 1. 问题

新标已经每天拉进采购监控（P2-1），也能一键跟进（P2-3a），但要有人自己打开监控页才看得到。TASKFLOW 的 P2-3 / GATE-2 要的是「早报里看到新标 → 一键跟进」；Muse 已永久冻结，早报要落在青砚自己的通知里。

## 2. 做了什么

- **07:00 一条「今日新标 N 条」**：已有的 `daily-brief`（每小时唤醒，只处理当地 07:00 的组织）多一步。已启用采购监控的组织，取首次发现在**前一天当地 07:00 到当天 07:00** 之间、还没截标（或截标未知）、没被忽略 / 归档 / 标为历史记录的招标公告；有的话发站内通知。
- **正文**：标题写总数；按发布日期新到旧列前 5 条「· 标题（截标 MM-DD HH:mm）」（多伦多时间，未知写「截标未知」，没有标题用编号）；多的写「另有 N 条」；末行「点开看采购监控 · 新标」。只含公开的标题、编号、截标时间。
- **发给谁**：与 PROC-1 扫描结果通知同一批人——监控开启人与创建人，去重；须仍是该组织在用成员且账号未停用。同一组织同一当地日期每人一条（重跑不重发、并发撞键跳过）。没有新标、监控未启用、采购监控闸关闭都不发。
- **点开去哪**：铃铛、通知页、邮件共用的跳转表加 `procurement_new_notices` → `/projects/intelligence/monitor?view=new`，打开前记住通知所属组织；监控页挂载时读 `?view=new`，直接选中「新标」筛选。
- 通知照常进 07:00 的每日未读汇总邮件（COLLAB-2；本步在邮件之前执行，当天早上的邮件就会带上）。不另发邮件、不发微信。

## 5. 独立审查

开 PR 前请了一个不带结论的独立审查（只给提交与四件套；它在隔离库跑了测试并试了变异）。没有 High。处理：

| 编号 | 发现 | 处理 |
|---|---|---|
| M1 | 「现在往前 24 小时」的窗口在夏令时切换日漏 / 重一小时（回拨日漏掉前一天 07:00–08:00 发现的，正好是 07:25 的每日扫描）；cron 启动秒数不同也会留缝 | 修。窗口改为 [前一天当地 07:00, 当天当地 07:00)，相邻两天首尾相接；design D2、spec 同步；测试覆盖两个切换日与 400 天连续性 |
| L1 | 排序用例在去掉排序时仍通过（插入顺序与发布顺序相同） | 修。三种顺序各不同；加无发布日期且发现最晚的一条 |
| L2 | 账号停用但成员关系仍在用的人照样收到 | 修。同时要求账号在用（与 COLLAB-2 汇总邮件一致） |
| L3 | 两次运行重叠时撞唯一键，异常中断本次其余收件人 | 修。撞键跳过这人、继续 |
| L4 | 「点开看全部」言过其实（新标视图列全部在招新标，不只今天的） | 修。改为「点开看采购监控 · 新标」 |
| L5 | 新类型没进通知类型标签 / 偏好开关，汇总邮件里归「其他通知」 | 不改。与 `revenue_owner_brief` 同一惯例；加开关会动通知偏好设置，另议 |
| L6 | 选监控的规则（最早启用的）与页面（最早建的）不同 | 修。与页面用同一函数 `getWatchRow` |

审查确认没问题的：组织隔离、新标口径与 P2-1 新标视图一致、去重、cron 出错不影响其他步骤、汇总邮件当天带上、`?view=new` 没有首屏不一致与请求竞态、客户端没有引入服务端模块、正文不含价格类信息。

## 6. 变异核对

- 第一轮 22 处（筛选、窗口、收件人、去重、闸、排序、当地日期、排版、跳转、记住组织、`?view=new`、cron 接线）：20 处被发现；「去掉发布时间排序」「按 UTC 取日期」存活，补用例（发现与发布反序、奥克兰时区）后被发现。
- 处理审查后复跑 28 处（加窗口两端开闭、固定 24 小时、07 点改 08 点、去掉全部排序、空值排前、停用账号）：28 处全部被发现。

## 7. 已知限制

- 通知里的 N 是「昨天 07:00 以来新发现的」，点开的新标视图列的是全部在招新标（截图里 3 条对 4 条），视图里不标哪条是今天的。
- cron 晚跑几分钟时，07:00 之后发现的留到第二天的早报（不漏）。
- 只发给监控开启人与创建人；要扩到招投标团队另做。
- 没有单独的开关：不想收的人目前只能停用采购监控（见 §5 L5）。

## 8. 没做的

预评分与按分排序（P2-2）、自动跟进、自动拉附件（P2-3c）；改扫描、排期、PROC-1 的扫描结果通知；微信推送、单独的邮件。

## 9. 上线

合并后照常部署。零 schema、没有开关：已启用采购监控的组织第二天 07:00 起开始收到（有新标时）。回滚 = 回滚代码。
