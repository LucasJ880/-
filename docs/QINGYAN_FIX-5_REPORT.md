## 1. 问题

招投标项目每推进一个阶段，`src/lib/tender/stage-tasks.ts` 本该做两件事：把上一阶段的自动任务标为完成；为新阶段建两三条任务（「[项目解读] 精读招标文件」之类）。第二件事建任务时给每条写了 `sortOrder`，任务表没有这一列，每次都报「Unknown argument `sortOrder`」；调用方不等结果、只打一行日志。所以**这些任务从来没有建出来过**。这个文件没有任何测试。

另外，模板把「准备投标文件」「提交投标」排在「项目提交」阶段——可进入那个阶段就意味着标已经交了。修好之后不调整，每次记下「已提交」都会冒出一条三天后到期的「提交投标」。

## 2. 做了什么

1. 建任务不再写那个不存在的列。要建哪些任务抽成一个纯函数 `buildStageTaskRows`，只产出任务表里有的九项。
2. 「准备投标文件」「提交投标」挪到「供应商报价」阶段的末尾；进入「项目提交」不建任务。进入「项目提交」时，它们随「[供应商报价]」的任务一起被关掉。
3. 「提交投标」的到期日取项目的截标时间；没有截标时间、或已经过了，仍按进入阶段后的天数算。
4. 同一批任务按模板里的先后顺序排：创建时间依次加 1 毫秒（任务表没有排序列，不为此加列）。

每个阶段建的任务：

| 进入阶段 | 任务 |
|---|---|
| 项目分发 | 分配项目负责人、初步评估项目可行性 |
| 项目解读 | 精读招标文件、确认投标资质要求、编制投标计划 |
| 供应商询价 | 发送供应商询价单、跟进供应商回复 |
| 供应商报价 | 汇总供应商报价、生成项目报价单、报价内部审核、**准备投标文件**、**提交投标**（到期日 = 截标时间） |
| 项目提交 | 不建 |
