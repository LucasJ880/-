## 1. 问题

询价的发件设置与落地价换算参数（汇率及其日期与来源、运费 / 保险 / 清关估算、项目关税率与交付截止）只能调 `PUT /api/organizations/[orgId]/tender-rfq-settings` 来改，没有页面。FLOW-H2 的「来自比价矩阵」要靠这些参数算落地价，没填的组织只会看到「换算不出」。

## 2. 做了什么

- **组织详情页多一节「询价与落地价设置」**，只在组织在用时、对组织管理员与平台管理员显示（与接口的权限一致）：
  - 发件显示名、显示地址、授权邮箱。没单独设置的项输入框为空，占位文字写「未单独设置，当前用：…」。
  - 汇率表（币种 → CAD）连同日期与来源；运费、出口内陆运费（按件 / 按票 / 按货值百分比）；保险费率；清关杂费；按项目的关税率与交付截止（从本组织的招投标项目里选）。
  - 写明用途（比价矩阵的落地价、报价表助手的成本建议）、两个地址的区别、GST/HST 不在这里填。
- **保存只发人改过的项**：没动的不发（回退值不会被写死）；改成空发 null；汇率改了就连同日期与来源一起发；授权邮箱没单独存而显示地址改了，把授权邮箱固定为改之前实际用的那个（发信账号不会悄悄变）。页面上先做与接口相同的校验，有错列出来、不调接口。
- **接口两处补充**：GET 多返回 `stored`（发件三项各自是不是组织自己存的）；PUT 里项目设置为 null（删除）不再校验项目归属（项目可能已被删除），写入的仍校验。
- 页面状态放进纯函数 reducer（`settings-section-state.ts`），读、改、存、出错每一步都能测。

## 5. 独立审查

开 PR 前请了一个不带结论的独立审查（只给分支与四件套；它在自己的工作区里跑测试、用真实路由逐条验证、做了 37 处变异）。没有高等级问题。处理：

| 编号 | 发现 | 处理 |
|---|---|---|
| M1 | 授权邮箱没单独存时跟着显示地址回退；只改显示地址就把发信账号也带走了。根因是 GET 只给解析后的值，页面分不清存的与回退的 | 修。GET 多返回 `stored`；没存的项显示为空、占位写回退值；这种情况下把授权邮箱固定为改之前实际用的那个。隔离库测试覆盖 |
| M2 | 项目被删除之后，它在设置里的那一行删不掉（接口按归属拒绝），连带别的修改都存不了 | 修。接口里删除（null）不校验归属，写入的仍校验 |
| M3 | 汇率整张发、日期与来源只在改了时发：两人同时改，一个人的汇率挂上另一个人的日期与来源 | 修。改了汇率就三项一起发 |
| L1 | `type=number` 打错字时值为空，会把存的值清掉 | 修。改为文本框 + `inputMode="decimal"`，打错的写明 |
| L2 | 页面校验与接口不一致（按货值百分比 > 100、存量日期缺失时只改发件也被拦、邮箱规则） | 修。去掉多余的限制；只有写落地价参数时才查汇率规则；邮箱用与接口相同的 zod 规则 |
| L3 | 存量里只有不合法的汇率（只能绕过接口写进去）时，落地价参数一直存不了 | 不修，写进 design Risks |
| L4 | 读失败一律悄悄隐藏；保存后重新读取失败时整节消失；项目列表失败没提示 | 修。只有 403 隐藏，其它显示错误；保存成功用 PUT 返回的设置；项目列表失败给提示并禁止新加 |
| L5 | 新加的项目行什么都没填也会存一条空设置 | 修。页面写明，不发 |
| L6 | 组织已归档时仍可编辑；切换组织时状态不重置 | 修。只在组织在用时显示；按 `orgId` 作 key |
| L7 | 任务没打勾、缺截图与报告；TASKFLOW 的 W-2 行仍列着回复提前量等 | 补齐；那三项另列 W-2b |
| 变异 | 组件状态 11 处变异 10 处存活；纯规则有 M18（只改交付截止）、M12（数值 0）与边界几处存活 | 状态挪进 reducer 并逐条测；补了这些用例 |

## 7. 已知限制

- **授权邮箱被固定**：原来跟着显示地址或环境变量回退的组织，改了显示地址之后授权邮箱成了固定值，以后改环境变量不再影响它。有意如此（发信账号不能因为改显示地址而变）。
- **存量不合法汇率**（见 L3）。
- **同一项两个人都改**：后保存的生效。
- **回复提前量、轮次锁、催单天数**：现有接口不收，页面上没有（W-2b）。

## 8. 没做的

- 扩接口支持回复提前量、轮次锁、催单天数（W-2b）。
- 改换算规则、默认值、权限。

## 9. 上线

合并后照常部署。零 schema，无回填，没有开关：组织管理员在组织页上就能看到并修改（每次保存都记审计）。接口的两处补充向后兼容（GET 多一个字段；删除放宽）。回滚 = 回滚代码。
