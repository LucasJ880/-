ai-markdown-image-allowlist 浏览器实测（2026-11-15）

环境
  本机 next dev（端口 3100）+ 本机 Postgres 16 隔离库（全部 migration 已应用）+ Chromium（Playwright 驱动）。
  Node 22.23.4（仓库要求 24，这台机器上没有 24；只影响本次实测与本地测试的运行环境，不影响结论）。
  登录身份：隔离库里新建的一个测试用户（平台 super_admin + 该测试企业的 org_admin），会话 cookie 直接签发。

做法
  1. 在隔离库里建一个对话，放一条用户消息和一条助手消息。助手消息的正文含：
     行内外部图片、引用式外部图片、协议相对地址的图片、包在链接里的外部图片、
     指向站内其它接口的图片（/api/auth/logout）、站内文件图片（/api/files/ai-chat/<org>/demo.png）、
     文字与去向不一致的外部链接、站内链接。
  2. 「外部主机」用本机另起的一个 HTTP 服务（127.0.0.1:4777）代替，它记录收到的每一个请求。
     对页面（localhost:3100）来说它是另一个源。四张外部图片的地址里各带一段 SECRET_* 查询串。
  3. 用真实页面打开 /assistant?thread=<id>，等页面静止后，记录浏览器发出的全部请求，
     并读出助手气泡里的图片元素、链接属性与提示文字。
  4. 对照：检查完之后在同一页面里手工插入一张指向 127.0.0.1:4777 的图片，
     确认这套监听确实抓得到外部请求（否则「零请求」没有意义）。
  5. 同一条消息、同一套脚本，在改动前的代码上再跑一遍作为对比。

没有照实做的一处
  本机没有 Blob 存储，/api/files/** 的响应在浏览器侧用一张纯色占位图顶替。
  浏览器确实向本站的 /api/files/ai-chat/<org>/demo.png 发了请求（计数 1），
  但「鉴权代理把真实文件流回来」这一步没有在本次实测里验证（该代理本 change 没有改）。

结果：改动后
  浏览器请求总数 73，其中发往本站以外的：0。
  「外部主机」服务收到的请求：0。
  助手气泡里的图片元素：1 个，src=/api/files/ai-chat/<org>/demo.png，已加载。
  被拦下的图片显示为：
    〔图片未加载：客户报价单 · 127.0.0.1〕
    〔图片未加载：引用式 · 127.0.0.1〕
    〔图片未加载：协议相对 · 127.0.0.1〕
    〔图片未加载：点击查看 · 127.0.0.1〕   （在原来的链接里面，链接后面另有主机名）
    〔图片未加载：退出〕
  没有对 /api/auth/logout 的请求。
  外部链接：href 不变，target=_blank，rel=noopener noreferrer nofollow，后面显示（127.0.0.1）。
  站内链接：没有 target，没有 rel，后面没有主机名。
  对照图片：浏览器请求记录与「外部主机」服务都记到了 /control.png。
  截图：01-after-assistant-reply.png（气泡）、02-after-assistant-page.png（整页）。

结果：改动前（同一条消息）
  发往「外部主机」的请求 4 个，查询串原样带出：
    GET /inline.png?d=SECRET_INLINE
    GET /ref.png?d=SECRET_REF
    GET /protorel.png?d=SECRET_PROTOREL
    GET /nested.png?d=SECRET_NESTED
  另有一个带登录态的站内请求：GET /api/auth/logout（由图片写法触发）。
  助手气泡里的图片元素：6 个。
  截图：03-before-assistant-reply.png。

没有覆盖的部分
  - 只实测了助手对话页。外贸对话、市场情报两个面板、标讯情报卡用的是同一个渲染组件，
    由 src/components/__tests__/ai-markdown.test.tsx 的源码断言保证，没有逐页开浏览器。
  - 没有用真实模型、真实邮件：助手消息是直接写进库里的。本 change 管的是「这段文字渲染出来之后
    浏览器会不会自己发请求」，与文字是谁写的无关。
  - 没有截开发者工具的网络面板；用请求记录代替（上面的数字来自 Playwright 的 request 事件
    与「外部主机」服务自己的访问记录，两边一致）。
  - 驱动实测的两段临时脚本（建数据、开浏览器）没有入库。
