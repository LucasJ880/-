site-csp-baseline · 文件代理与三种运行模式的本地实测（2026-11-16）

做法：本地 Postgres + next dev，文件存本地目录（PRODUCT_CONTENT_LOCAL_STORE=1）。
1. 以企业负责人身份经真实上传接口 POST /api/product-content/upload 传入两份文件：
   一份内容类型为 text/html、带一段把标题改成「RAN」的脚本；一份 application/pdf。接口都接受了。
2. 以同企业另一名成员（销售）的身份，用 Chromium 直接打开网页文件的文件代理地址，
   看响应头与标题有没有被脚本改掉（scriptRan）。
3. 服务分别以 CSP_MODE 未配置 / off / report-only 启动，各跑一遍；顺带记录登录页的响应头。

结论：强制与 report-only 模式下网页文件带 sandbox、脚本没有执行、文字照常显示；
off 模式（等于改动之前）脚本执行了。PDF 三种模式都不带内容安全策略响应头。未登录一律 401。
