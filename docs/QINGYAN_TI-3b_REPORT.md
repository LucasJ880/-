## 2. 阶段策略表

这是「只读的事不再逐项询问」的落点。每个阶段的决定只能是六个取值之一：执行、等材料、未接通、仅人工、停下等批准、已关闭。**类型里没有「询问是否执行」这个取值。**

| 阶段 | 类别 | 需要的材料 / 来源 | 缺省情形下的决定 |
|---|---|---|---|
| 文件接收 | 等材料 | 招标文件 | 有文件即执行 |
| 文件领取方分析 | 等材料 | 文件领取方名单 | 有名单即执行，没有就等材料 |
| 历史授标与采购 | 取决于来源 | 官方授标与合同披露（缺省仅人工） | 仅人工；人工提供了记录则执行 |
| 进口线索 | 取决于来源 | 授权贸易数据（缺省未接通） | 未接通；人工录入了线索则执行 |
| 供应商匹配 | 自动 | 招标文件 | 执行 |
| 合规对照 | 自动 | 招标文件 | 执行 |
| 成本核算 | 自动 | 招标文件、供应商报价 | 有报价即执行，没有就等材料 |
| Owner 决定 | 要批准 | — | 停下等批准 |
| 标书准备 | 自动 | 招标文件 | 执行（只出草稿） |
| 供应商外联 | 要批准 | — | 停下等批准 |
| 政府资料申请 | 要批准 | — | 停下等批准 |
| 提交 | 要批准 | — | 停下等批准 |
| 截标后复盘 | 自动 | 开标或授标结果 | 有结果即执行 |

「要不要查海关数据」在这张表里的答案是：接通了就查；没接通就在结果里写「未接通——这不表示没有记录，而是没有查」；人工录入了线索就只处理录入的。三种情形都不问。

组织可以关闭某个阶段，但不能把四个要批准的阶段改成自动——这样的覆盖会被拒绝。

以渥太华为例，只提供了招标文件与领取方名单、来源为缺省状态时，三张清单是：

- 缺材料：成本核算缺供应商报价；截标后复盘缺开标或授标结果。
- 未接通 / 仅人工：进口线索（授权贸易数据未接通）；历史授标与采购（仅人工）。
- 等批准：Owner 决定、供应商外联、政府资料申请、提交。

## 5. 几条规则的取舍

- **可投标只有两个结果**：不可投标、可提交 Owner 决定。没有「有条件可投」——条件本身就是阻断项，列出来即可。「可提交 Owner 决定」的说明文字写明这不是批准，也不代表可以直接投标；输出里没有任何批准或已提交的字段。
- **哪些是阻断项，哪些只是提示**：已过截标、价格表结构无效、任一行成本为空、成本含未核实的关税假设、尺寸不符或无法判断、认证未过、补遗后有待复核的结论——都是阻断项。含指示性价格（平台标价、零售价、估计）只是提示：用它去投是商业判断，由 Owner 决定。
- **尺寸「无法判断」算阻断**，与供应商情报里「未知永不折算通过」的既定规则一致。
- **认证闸比供应商情报现有的认证规则严。** 那里范围为「整个供应商」的已核验证书即可通过；这里必须覆盖整机且型号一致。两处回答的问题不同（「这家供应商有没有这类资质」对「这个型号的整机有没有证」）。以后在界面上并排显示时要讲清楚，免得同一张证书一边绿一边红让人困惑。
- **「已核验」「受认可」「覆盖整机」都是输入**，缺省是未确认，未确认即不通过。本模块不核验证书真伪，不内置发证机构名录。
- **证据状态是投影，不新增存储值**；置信度（高 / 中 / 低）不进投影，单独显示。
- **补遗失效只按「行 + 版本」判断**，不解析补遗正文；哪份补遗影响哪些行由上游给出。
