# 北美家纺合规与规格知识包（na-home-textile）

面向国内家纺工厂（浴袍/毯子/毛巾）对北美 B2B 买家的合规与规格知识，供导入外贸「产品知识库」（TradeKnowledge）。

- 8 篇 Markdown，均带 frontmatter（title / category / tags / language），可直接用「外贸 → 知识库 → 导入 .md/.zip」导入；
- 每条要点标注性质（强制法规 / 自愿认证 / 测试方法 / 市场惯例）与官方来源 + 核验日期（2026-09-05）；
- `00-总览与更新机制.md` §7 列出未能对官方原文核实的条目，引用时按「待核实」处理；
- `watch-sources.json`：值得长期监测的官方页面，用于「市场监测」挂靶（页面变化 → 提示标准可能更新）。

修订流程：改本目录文件 → 重新导入（同标题条目先在知识库停用旧版）→ 更新核验日期。
