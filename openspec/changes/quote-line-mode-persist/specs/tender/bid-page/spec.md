# Spec Delta

## MODIFIED Requirements

### Requirement: 「下一步」指向哪里
「下一步」 SHALL 按规则指向固定的去处：招标分析没批准 → 切到「招标要求」页签；没有供应商、没发过询价、等批准后发出、等供应商回复、看供应商回复把报价录入 → ①；检查后定为我方报价、开始做报价 → ②；导出价格表 / 生成投标文件 → ③，但我方报价是逐行报价时 → ②（按招标方价格表导出在 ② 底部）。按钮文字 SHALL 是「去「招标要求」」或「去「<分区名>」」。

#### Scenario: 每条规则的去处
- **WHEN** 逐条取规则的去处与按钮文字，「已定」分别取我方报价是 / 不是 / 不知道是不是逐行报价
- **THEN** 与上表一致：「已定」在我方报价是逐行报价时是「去「定报价」」，其余是「去「出文件」」（`npx tsx src/lib/bid-page-v2/__tests__/next-step.test.ts`）

### Requirement: 新页面不给看不到金额的人显示带金额的旧组件
新页面 SHALL 只在汇总接口标明能看金额时显示带金额的区块（询价轮次及其中的供应商报价、我方报价卡、报价区、旧版报价单（外贸标准报价）、「更多」里的版本历史）；标明不能看时 SHALL 在 ① 显示「询价里会有供应商报价，所以询价区只给项目负责人和有财务查看权的同事看。要起草或查看询价，请找他们。」、在 ② 显示「报价的金额与成本只给项目负责人和有财务查看权的同事看。要做报价或查看金额，请找他们。」，SHALL NOT 显示这些区块与「更多」。这一门只决定新页面挂不挂这些区块，旧接口的口径不在本能力内。新页面 SHALL NOT 挂投标工作区面板与改版前的报价区（它们在改版前的页面上照旧）。

#### Scenario: 看不到金额的人在新页面上看不到带金额的区块
- **WHEN** 汇总接口标明不能看金额，渲染新页面
- **THEN** 页面上没有询价区、报价区、「更多」，源码里我方报价卡、报价区、旧版报价单、版本历史抽屉只在能看金额的分支里；① ② 各有那一句说明；投标价区块的位置仍在（`npx tsx src/components/bid-page-v2/__tests__/bid-page-v2.test.tsx`）

#### Scenario: 看得到金额的人照常
- **WHEN** 汇总接口标明能看金额（报价功能开或没开），渲染新页面
- **THEN** 询价区、报价区、「更多」都在，没有那两句说明；新页面源码里没有投标工作区面板与改版前的报价区（同一测试）

### Requirement: 页内位置照常可达
新页面 SHALL 保留改版前页面上供项目页「下一步」卡跳转的位置：供应商询价区块（看得到金额时）、投标价区块（两种人都有）。地址里的 `#位置` 落在某个分区里（含改版前投标工作区的位置，对应 ②）时，新页面 SHALL 展开该分区并自己滚动到位置一次（位置不在页面上时只展开分区）。

#### Scenario: 从项目页「下一步」卡跳到投标价
- **WHEN** 地址带 `#bid-quote-area`（或 `#rfq-section`、`#rfq-round-…`、`#bid-workspace`）打开新页面，「下一步」指向别的分区
- **THEN** 对应的分区（② 或 ①）优先展开；展开后滚到位置；带 `bid-quote-area` 的元素在页面上（`npx tsx src/components/bid-page-v2/__tests__/bid-page-v2.test.tsx`）
