# Proposal：招标价格表行项——契约、单位换算、尺寸对照、截标校验、原样导出

TASKFLOW：TI-1（Phase F，Tender Intelligence Phase B 第一项；来源 `docs/tender-intelligence-gap-analysis.md` §6 的 N1、N2、N11，Owner Gate A 已拍板）。

## Why

青砚没有「价格表行项」这个概念：要求只有文本，询价单只认一个总数量，按行报价、按行算成本、按官方价格表导出都无从做起。渥太华 18026-93121-T01（18 行，单位有 Each / Pack / Box / Roll）这类货物标因此只能在系统外手工核算。

## What Changes

- 新增价格表行项的数据契约：行号、说明、数量、单位、包装数、尺寸、是否带强制认证闸、出处。
- 新增行项结构校验：行号从 1 连续且唯一、数量为正、单位在目录内、包装数为正整数；有问题逐条列出，不自动修正。
- 新增按行号集合的数量汇总，用于核对整张价格表。
- 新增单位换算：供应商按件报价时，换成招标单位的单价（每包 2 件、每盒 12 件、每卷 25 件），招标数量与单位保持不变，换算只做一次。
- 新增金额规则：单价先四舍五入到分，再算行合计与总计，合计与逐行相加一致到分。
- 新增尺寸对照：把招标尺寸（定值、区间、最小值）与供应商产品尺寸逐维比较，给出相符 / 不符 / 无法判断；无法判断不算相符。
- 新增截标时间校验与状态推导：不带时区的时间不接受；未过截标为开放，已过且有回执支撑的提交为已提交，已过且没有为已过期。
- 新增官方价格表导出：行序、行号、说明、单位、数量与输入完全一致，任何一行缺单价就拒绝导出。
- 新增渥太华回归夹具（竞争对手与出口商名称用代号）与对应测试。

本次只交付纯函数与测试：不接界面、不落库、不联网、不调模型。线上行为零变化。
