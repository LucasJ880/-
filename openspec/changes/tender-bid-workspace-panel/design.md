# Design

## Context

- TI-4a 提供三个接口，开关默认关；关闭时 404。
- 「标书与报价」页签（`src/components/project-detail/tabs/bid-tab.tsx`）是一列卡片，各卡片自己取数。
- 成本输入不落库（`docs/QINGYAN_TI-4a_REPORT.md` §3），所以界面要自己保留输入。
- 页面受路由门约束，但本次不新增页面，只在既有页面里加一个组件。

## Goals / Non-Goals

**Goals:**

- 让判定、清单与核算表在项目页上看得见。
- 开关关闭时页面零变化。

**Non-Goals:**

- 不动 `bid-tab.tsx` 里既有卡片的顺序与行为（只在顶部加一行挂载）。
- 不动 `src/lib/tender/workbench-state.ts`、工作台页签、进度条。
- 不动任何接口与 `src/lib/tender-bid-workspace/` 里 TI-4a 的四个文件。
- 不新增页面，不动路由门表与导航注册表。

## Decisions

### D1：一个自取数的客户端组件，404 时返回空

组件挂载后请求读取接口：200 才渲染，404 返回 `null`。不在服务端判断开关再决定是否挂载。

- 被否决：由页面把开关状态作为属性传进来。要改页面的数据加载，而且开关还带组织白名单，判断逻辑会在两处各写一遍。
- 被否决：开关关闭时显示「未启用」占位。验收 A20 要的是开关关闭不改变现有页面。

### D2：粘贴导入而不是逐格编辑

价格表与领取方名单都用「粘贴 → 预览 → 保存」。解析是纯函数，放在 `src/lib/tender-bid-workspace/paste-import.ts`，可单测。

- 被否决：做可逐格编辑的表格。价格表本来就是从发标方的工作簿来的，粘贴最快，也最不容易在手工录入时把单位改掉。
- 被否决：上传 xlsx 在服务端解析。要动上传与解析链路，属于另一个 change；粘贴先解决 18 行这种规模。

### D3：成本输入存浏览器本地，按项目分键，可导出导入

`localStorage` 键为 `qy.bidWorkspace.costDraft.<projectId>`。面板上常驻一句「成本输入只保存在这台设备的浏览器里」。

- 被否决：存服务端。存储位置待 Owner 决定。
- 被否决：不保存，刷新即丢。18 行输入重填一遍不可接受。

### D4：成本输入的组装是纯函数

`cost-draft.ts` 把界面草稿（逐行字段 + 情景设置）变成接口请求：没填报价的行不进请求（接口会把它们作为「缺供应商报价」显示）；非加元币种的汇率、来源、日期取自草稿的汇率表。

- 被否决：在组件里直接拼请求。拼错的后果是算错钱，值得单测。

### D5：核算表直接渲染接口返回的视图

组件不做任何金额运算，只把视图里的字符串排进表格。

- 被否决：前端自己算合计或比率。数字只算一次是 TI-2 的设计原则。

## 与八条硬纪律的关系

1. 零 schema：不涉及。
2. 出站先审批：不涉及。面板没有任何对外动作；「等批准」清单只是显示。
3. 禁止第三套队列：不涉及。
4. 脱敏：触碰——面板会显示成本、报价与毛利。这些只来自成本核算接口，接口已按财务查看权控制；面板不把它们发往任何其它地方。成本输入存浏览器本地，不上传保存。
5. 不爬登录页：不涉及。
6. 邮箱分离：不涉及。
7. 确定性优先：遵守。零模型调用。
8. 测试注册：新增 1 个纯逻辑测试，登记进 `scripts/test-all.sh` 与 `scripts/test-ci-unit.sh`。

## 验证方式

- `npx tsx src/lib/tender-bid-workspace/__tests__/panel-helpers.test.ts`
- 真实应用：本地 PostgreSQL + `next dev`，用浏览器自动化登录后截图三张——开关关闭、总览、核算表，存 `docs/acceptance/ti-4b/`。
- `bash scripts/check-test-registry.sh`、`npm run typecheck`、`npm run lint:baseline`、`openspec validate tender-bid-workspace-panel --strict`

## Risks / Trade-offs

- [成本输入在浏览器本地，换设备就没了] → 面板写明，并提供导出 / 导入；Owner 定了存储位置后改为服务端保存。
- [共用电脑上别人能看到本地的成本输入] → 面板写明「只保存在这台设备」；提供「清空」。
- [面板放在页签顶部，会把既有卡片往下推] → 只在开关打开时出现；位置可以在评审时调整。
- [截图用的是合成数据] → 截图说明里写明。
